Módulo 02

Criar PROMPTS: Como conversar com a IA?

Fórmula de Ouro

Contexto + Objetivo + Público + Formato + Detalhes = Melhores Resultados!

Elemento O que informar? Exemplo
Contexto Explique a situação "Comunicar atraso na entrega..."
Objetivo O que espera da IA "Criar um e-mail profissional."
Público Quem receberá "Destinatário é cliente VIP."
Formato Especifique a saída "E-mail, Tabela, PDF, Excel..."
Detalhes Tom, tamanho, regras "Tom formal, até 200 palavras."

Evite Prompts Fracos

"Crie um e-mail sobre atraso na entrega por conta do problema X."

Motivo: Gera respostas genéricas e sem tom adequado.

Prompt Estruturado Perfeito

"Crie um e-mail profissional para um cliente informando atraso na entrega devido a problemas de transporte. Explique o ocorrido de forma transparente, informe a nova previsão de entrega e mantenha um tom cordial."

Módulo 03

Como solicitar uma Macro para a IA?

1. Mapeie

Defina o resultado e etapas repetitivas.

2. Grave

Explique colunas, abas e filtros passo a passo.

3. Evidências

Anexe transcrição, prints e o prompt detalhado.

4. Teste

Execute o código VBA inicial com poucas linhas.

5. Refine

Erros acontecem. Ajuste e interaja com a IA!

Modelo de Prompt para Pedir VBA 
"Analise esta transcrição da gravação de tela. Também estou enviando imagens das planilhas. Identifique: onde clico, quais filtros aplico, colunas utilizadas e fórmulas.
Com base nisso:
1. Gere uma macro VBA que reproduza exatamente o processo;
2. Comente o código para facilitação de manutenção;
3. Explique como instalar no Excel e criar o botão de disparo."
